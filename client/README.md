# EcoAlerta
Proyecto para la materia Aplicaciones moviles, una app para denunciar microbasurales y focos de dengue.

Primero clonar el repositorio de Github a una carpeta que podamos encontrar con facilidad.

git clone https://github.com/Panconmatecocido/EcoAlerta.git

Segundo revisar que esten parados en la carpeta raiz para poder hacer:

npm install


con esto ya deberian tener lista la estructura.

no olviden de crear la rama del laburo que van a llevar a cabo. 

git checkout -b <nombre-rama>

### 🔍 Estructura de Gobernabilidad de la Matriz
1. **Trazabilidad Hacia Adelante (Forward Traceability):** Permite verificar que el 100% de las Historias de Usuario (HU), Requisitos Funcionales (RF) y Requisitos No Funcionales (RNF) cuenten con al menos un caso de prueba asociado, eliminando brechas de cobertura.
2. **Trazabilidad Hacia Atrás (Backward Traceability):** Vincula de forma directa cada defecto detectado (Bug ID) con el caso de prueba que lo evidenció, el requisito de origen y el **integrante responsable unívoco de corregirlo**.
